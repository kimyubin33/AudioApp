# 디자인 언어: 먹과 화선지

**구조는 YouTube 모바일처럼, 질감은 붓으로 쓴 먹처럼.** 흰 종이 위의 검은 먹, 그리고 그 사이의 번짐(회색 농담)만 쓴다.
빨강·파랑 같은 색은 쓰지 않는다. 극도로 단순하게.

## 구조 (YouTube 모바일 참고)

| 화면 | 구성 |
|---|---|
| 홈 | 위에 붓글씨 로고, 아래로 큰 썸네일 카드가 쌓이는 피드. 카드 = 16:9 먹 그림 + 크리에이터 도장 + 제목 + 보조 정보 |
| 시청 | 위쪽에 영상(음원은 먹 그림)을 화면 폭 가득. 아래에 제목, 크리에이터, 진행선, 재생 조작, 신고·차단 |
| 미니 플레이어 | 홈 하단, 탭 막대 바로 위. 작은 먹 썸네일 + 제목 + 재생 버튼 |
| 하단 탭 (4개) | **오디오** (채널이 만든 오디오, 실시간 오디오는 나중에) · **숏츠** (AI 숏폼, 세로로 넘기는 전체 화면, 미니 플레이어 숨김) · **구독** (구독한 채널의 영상·오디오, 로그인 필요) · **보관함** (기록·저장은 기기 안에만, 차단 관리) |

## 색 (`ui/theme/Color.kt`)

| 이름 | 값 | 쓰임 |
|---|---|---|
| Paper | `#FBFBF8` | 화선지 바탕. 순백보다 아주 살짝 따뜻해서 먹이 깊어 보인다 |
| PaperDeep | `#F1F0EB` | 썸네일 바탕, 종이결 |
| Ink | `#0C0C0C` | 먹. 글씨, 재생 버튼, 도장 |
| InkSoft | `#2A2A29` | 묽은 먹 |
| Ash | `#6E6E6B` | 보조 글씨 |
| Mist | `#DCDBD6` | 가는 선, 비활성 |

시스템 다크 모드와 동적 색상(Material You)은 쓰지 않는다. 종이 위에 먹, 이 한 가지 모습만.

## 글꼴 (`ui/theme/Type.kt`, 내장, 둘 다 SIL OFL — 라이선스는 `docs/licenses/`)

- **나눔 붓글씨**: 로고와 화면 제목에만 아껴서. (`displaySmall`, `headlineSmall`)
- **고운바탕**: 곡 제목처럼 읽는 글. (`headlineMedium`, `titleLarge`, `titleMedium`)
- 기본 고딕: 보조 정보와 버튼. 글자 사이를 조금 띄워 차분하게.

글꼴 파일은 `python scripts/fetch_fonts.py` 로 받는다 (Git에도 올라가 있다). 글꼴이 앱 크기를 약 12MB 늘린다. 줄이려면 자주 쓰는 한글만 남기는
서브셋을 만든다 (없는 글자는 기본 글꼴로 대신 나온다).

## 먹 그림 (`ui/InkArt.kt`)

곡마다 다른 썸네일을 **이미지 파일 없이 코드로** 그린다. 곡 id가 같으면 언제나 같은 그림이다.
서버가 진짜 썸네일을 줄 수 있게 되면 그 이미지가 있을 때만 대신 쓰고, 없으면 이 먹 그림이 나온다.

- 음원: 한 번에 그은 **원상(엔소)**. 시작은 먹이 진하고 끝은 마른 붓결(비백)로 날린다. 열린 틈과 크기가 곡마다 다르다.
- 영상: 대각선으로 내리긋는 **획 두 줄**, 오른쪽 아래에 작은 재생 표시.
- 공통: 종이에 스민 옅은 먹물, 튄 먹방울 몇 점.
- 주의: 그림은 `clipToBounds`로 영역 밖으로 번지지 않게 한다.
- 주의: 획의 경로 안에서 난수를 뽑지 않는다 (점마다 경로가 흔들려 획이 찢어진다). 제어점은 한 번만 정한다.

## 작은 요소들

- **구분선(`InkDivider`)**: 양 끝이 가늘고 가운데가 살짝 굵은 한 획의 선.
- **진행선(`InkSeekBar`)**: 지나온 부분은 가늘게 시작해 굵어지는 붓 자국, 끝에 먹점. 눌러서 또는 끌어서 이동. 화면 낭독기에서는 진행바로 읽힌다.
- **크리에이터 도장(`CreatorMark`)**: 검은 동그라미에 크리에이터 id 끝 두 글자를 붓글씨로.
- **"AI 생성" 표시**: 낙관처럼 얇은 먹 테두리 + 모서리 2dp. 모든 콘텐츠에 반드시 보인다.
- **탭 아이콘**: 라이브러리 없이 끝이 둥근 선으로 직접 그린다. 선택된 탭은 아래에 작은 먹점.
- **모서리**: 둥글지 않고 단정하게 (2~8dp).
