# AI & ME 디자인

사진 한 장, 목소리, 짧은 영상으로 기억을 남기고 다시 감상한다.
첨부된 ‘추억 앨범 기술 설계서 v0.3’의 제품 방향과 흰 종이·검은 먹 시안을 따른다.
장소와 차량은 이야기를 다시 발견하는 통로다. 위치 권한을 기본 사용 조건으로 만들지 않는다.

## 화면 구조

| 화면 | 구성 |
|---|---|
| 피드 | 글자 대신 벡터 심볼, 검색·카메라, 전체·오디오·쇼츠 필터와 16:9 콘텐츠 카드. 소개 문구와 스트리머 진입 버튼 없음 |
| 지도 | 장소 이름으로 기존 공개 이야기 검색. ‘내 주변’을 누른 경우에만 위치 권한과 기본 1km 탐색. 결과의 공개 장소를 외부 지도 앱에서 열기 |
| + 창작 | 스트리머 모드를 바로 연다. 파일·ZIP 업로드, 미리보기와 권리 검토. 사진·글 작성은 상단 카메라의 Moment 또는 계정 메뉴의 Moments → New에서 연다 |
| 구독 | 구독한 크리에이터의 오디오·쇼츠. 친구 피드와는 다른 기존 기능 |
| 보관함 | Saved / History에 집중. 상단 원형 계정 버튼은 비로그인 시 사람 아이콘·로그인, 로그인 시 설정한 프로필을 표시 |
| Account | 프로필 수정, Moments, 차단 목록, 시청 기록 삭제, 앱 권한, 로그아웃 |
| Profile | 계정별 이름·사진 설정. 이 기기에 저장. 선택 사진은 즉시 저장하고 이름은 Save로 확정 |
| 시청 | 기존 Media3 플레이어, 자막 등 콘텐츠 정보, 신고·차단·저장·구독 |
| 쇼츠 연속 보기 | 피드의 쇼츠 필터에서 진입. 기존 세로 넘김·반복 재생·신고·차단 유지 |
| 미니 플레이어 | 재생 서비스는 화면 이동과 회전에도 유지. 홈의 탭 바로 위에 표시 |

하단은 **피드 · 지도 · + 창작 · 구독 · 보관함**의 5개 메뉴다.
소개·홍보 문구를 표시하지 않고, 기능 이름·콘텐츠 정보·필수 안내만 간단히 남긴다.
브랜드는 ic_brand_mark.xml의 오디오 파형과 사람을 잇는 자체 벡터 심볼로 표시한다. 네 갈래 별과 Google/Gemini 로고 파일은 사용하지 않는다. 글꼴로 로고를 그리지 않는다.
상태 표시줄과 제스처 영역은 OS에 맡긴다. 본문 최대 폭을 제한해 큰 창에서도 읽기 편하게 한다.
긴 편집 화면은 스크롤하며, 초안은 ViewModel과 기기 저장소에서 복원한다.

## 추억 작성과 스트리머 모드

카메라 편집 화면의 이름은 Moment다. Add Photo / Change Photo / Save Moment를 사용하고 필드·권리 안내는 한국어를 유지한다.
사진 추억은 제목·글·선택적인 장소 이름으로 구성한다. 현재 구현은 기기 전용 비공개 앨범이다.
친구 공개·전체 공개·차량 허용처럼 서버 권한이 필요한 선택지를 작동하는 것처럼 표시하지 않는다.
사진은 선택기에서 한 장만 읽고, 방향을 반영해 JPEG로 다시 인코딩하며 EXIF 위치 정보를 제거한다.
사진 원본 URI와 사용자 현재 좌표는 앨범에 남기지 않는다.

‘AI로 꾸며보기’는 사용자가 펼칠 때만 보인다. 그날의 분위기·20초 목소리·15초 쇼츠 프롬프트를 복사한다.
외부 AI를 직접 호출하지 않는다. 현재 글과 가져온 후보는 구분해 저장하고, 채택 후에도 이전 글로 되돌릴 수 있다.
외부 AI 계정·대화 내역은 수집하지 않는다.

스트리머 모드는 하단 + 창작에서 바로 연다. 실시간 방송이 아니라 기존 크리에이터 업로드·관리 기능이다.
파일 확인 → 콘텐츠 정보 → 권리 확인 → 선택적 장소 연결 → 최종 검토의 5단계와 여러 파일·ZIP 처리를 유지한다.
R2 비공개 저장, 승인·반려·수정 제출 규칙을 바꾸지 않는다.
차량에서 인기 게시물의 오디오를 추천하는 제품 방향을 유지하며, 기업 차량 SDK 연결은 보류한다.
서버 공개 범위와 차량 허용 정책의 확장 경계는 [추억 앨범 구현 범위](memory-album.md)를 참고한다.

## 글꼴 (`ui/theme/Type.kt`, 내장, 둘 다 SIL OFL — 라이선스는 `docs/licenses/`)

- **나눔 붓글씨**: 로고와 화면 제목에만 아껴서. (`displaySmall`, `headlineSmall`)
- **고운바탕**: 곡 제목처럼 읽는 글. (`headlineMedium`, `titleLarge`, `titleMedium`)
- 기본 고딕: 보조 정보와 버튼. 글자 사이를 조금 띄워 차분하게.

글꼴 파일은 `python scripts/fetch_fonts.py` 로 받는다 (Git에도 올라가 있다). 글꼴이 앱 크기를 약 12MB 늘린다. 줄이려면 자주 쓰는 한글만 남기는
서브셋을 만든다 (없는 글자는 기본 글꼴로 대신 나온다).

## 먹 그림 (`ui/InkArt.kt`)

곡마다 다른 썸네일을 **이미지 파일 없이 코드로** 그린다. 곡 id가 같으면 언제나 같은 그림이다.
서버가 진짜 썸네일을 줄 수 있게 되면 그 이미지가 있을 때만 대신 쓰고, 없으면 이 먹 그림이 나온다.

- 음원: 한 번에 그은 **원상(엔소)**. 시작은 먹이 진하고 끝은 마른 붓결(비백)로 날린다. 열린 틈과 크기가 곡마다 다르다.
- 영상: 대각선으로 내리긋는 **획 두 줄**, 오른쪽 아래에 작은 재생 표시.
- 공통: 종이에 스민 옅은 먹물, 튄 먹방울 몇 점.
- 주의: 그림은 `clipToBounds`로 영역 밖으로 번지지 않게 한다.
- 주의: 획의 경로 안에서 난수를 뽑지 않는다 (점마다 경로가 흔들려 획이 찢어진다). 제어점은 한 번만 정한다.

## 작은 요소들

- **구분선(`InkDivider`)**: 양 끝이 가늘고 가운데가 살짝 굵은 한 획의 선.
- **진행선(`InkSeekBar`)**: 지나온 부분은 가늘게 시작해 굵어지는 붓 자국, 끝에 먹점. 눌러서 또는 끌어서 이동. 화면 낭독기에서는 진행바로 읽힌다.
- **크리에이터 도장(`CreatorMark`)**: 검은 동그라미에 크리에이터 id 끝 두 글자를 붓글씨로.
- **"AI 생성" 표시**: 서버의 AI 생성 콘텐츠에 표시한다. 사용자의 사진·글 추억을 AI 생성으로 표시하지 않는다.
- **탭 아이콘**: 라이브러리 없이 끝이 둥근 선으로 직접 그린다. 가운데 창작은 먹빛 원 안의 +. 선택 상태는 접근성 Tab 의미와 먹/회색으로 구분한다.
- **모서리**: 카드 14~18dp, 입력·버튼 8~12dp. 큰 이미지는 카드 밖으로 넘치지 않는다.
