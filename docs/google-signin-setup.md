# Google 로그인 준비 (직접 하셔야 하는 작업)

앱에 Google 로그인을 붙이려면 Google Cloud 콘솔에서 **클라이언트 ID 두 개**를 만들어야 합니다.
Google 계정만 있으면 되고 **비용은 들지 않습니다.** 30분 정도 걸립니다.

> 아래 값들은 이 프로젝트에 이미 정해진 값입니다. 그대로 입력하세요.
>
> | 항목 | 값 |
> |---|---|
> | 앱 패키지 이름 | `com.kimyubin33.audioapp` |
> | 개발용(debug) 서명 지문 SHA-1 | `A7:98:65:10:0B:90:B4:E5:77:72:59:68:D7:CB:65:22:3B:66:D3:DA` |
>
> SHA-1은 인증서의 "지문"(공개 정보)이라 비밀이 아닙니다. 개인키는 PC 밖으로 나가지 않습니다.

## 1단계. 프로젝트 만들기

1. <https://console.cloud.google.com> 에 Google 계정으로 로그인합니다.
2. 맨 위 프로젝트 선택 상자 → **새 프로젝트** → 이름 `AudioApp` → **만들기**.
3. 만든 프로젝트가 선택된 상태인지 확인합니다.

## 2단계. 동의 화면(OAuth) 설정

사용자가 로그인할 때 보게 되는 화면입니다.

1. 왼쪽 메뉴 **API 및 서비스 → OAuth 동의 화면** (또는 "Google Auth Platform") → **시작하기**.
2. 앱 이름: 앱에서 보일 이름(지금은 `AudioApp`), 사용자 지원 이메일: 본인 Gmail.
3. 대상: **외부**.
4. 연락처 이메일: 본인 Gmail → 약관 동의 → **만들기**.
5. 처음에는 **"테스트" 상태**입니다. 이 상태에서는 **테스트 사용자로 등록한 계정만** 로그인할 수 있습니다.
   **대상(Audience) → 테스트 사용자 → 추가**에서 본인 Gmail과, 시험해 볼 다른 계정을 넣어 주세요.

## 3단계. 안드로이드용 클라이언트 ID

1. **클라이언트 → 클라이언트 만들기**.
2. 애플리케이션 유형: **Android**.
3. 이름: `AudioApp Android (debug)`.
4. 패키지 이름: `com.kimyubin33.audioapp`
5. SHA-1 인증서 지문: `A7:98:65:10:0B:90:B4:E5:77:72:59:68:D7:CB:65:22:3B:66:D3:DA`
6. **만들기**. (이 ID는 코드에 직접 쓰지 않지만, **있어야 안드로이드에서 로그인이 동작**합니다.)

> 나중에 Google Play에 올릴 때는 Play가 앱에 다시 서명하므로, **Play Console의 "앱 서명" 화면에 나오는 SHA-1**로
> 안드로이드 클라이언트를 하나 더 만들어야 합니다. 그때 안내드리겠습니다.

## 4단계. 웹용 클라이언트 ID (이게 제일 중요)

1. **클라이언트 만들기** 한 번 더.
2. 애플리케이션 유형: **웹 애플리케이션**.
3. 이름: `AudioApp server`
4. 승인된 리디렉션 URI 등은 **비워 둡니다.**
5. **만들기** → 화면에 나오는 **클라이언트 ID**를 복사합니다.
   `숫자-영문숫자.apps.googleusercontent.com` 모양입니다.

## 5단계. 저에게 알려 주실 것

- **웹 클라이언트 ID 한 줄**만 채팅에 붙여 넣어 주세요.
- 클라이언트 ID는 공개돼도 되는 식별자입니다. 앱 안에도 그대로 들어갑니다.
- **"클라이언트 보안 비밀(secret)"은 필요 없으니 절대 보내지 마세요.** (화면에 보이더라도 복사하지 않아도 됩니다.)

## 이 값을 어디에 쓰나

- **앱:** Google이 발급하는 ID 토큰의 "받는 사람"을 이 웹 클라이언트 ID로 지정해 로그인을 요청합니다.
- **서버:** 앱이 보낸 ID 토큰을 Google 공개키로 검증하면서, "받는 사람이 우리 웹 클라이언트 ID인지" 확인합니다.
  (다른 앱용으로 발급된 토큰으로 우리 서비스에 로그인하는 것을 막습니다.)

## 알아 둘 점

- "테스트" 상태에서는 등록한 테스트 사용자만 로그인됩니다. 출시할 때 **"프로덕션으로 게시"**하면 누구나 쓸 수 있습니다.
  이메일·프로필 기본 정보만 쓰므로 Google의 별도 앱 심사는 보통 필요 없습니다.
- 앱 이름·로고·개인정보 처리방침 주소는 게시 전에 동의 화면에 채워야 합니다.
