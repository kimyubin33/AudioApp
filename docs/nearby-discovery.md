# 선택적 주변 이야기 탐색

장소에 연결된 사람들의 추억과 창작물을 오디오로 발견하는 기능입니다. 첫 출시는 오디오에 집중하며 쇼츠·게시글은 후속 범위입니다. 현재 하단 **Drive → 내 주변**에서 전경 위치 탐색을 켜고 오디오 영역을 확인합니다. 크리에이터 모드는 **+ 창작**으로 엽니다. [실제 화면과 영상](../README.md).

## 현재 동작

- 사용자가 탐색을 켜면 전경 위치 권한을 요청합니다. Android 12 이상에서는 정확한 위치와 대략적인 위치 중 선택할 수 있습니다. 대략적인 위치만 허용해도 탐색합니다. OS가 대략적인 위치를 느리게 갱신하거나 네트워크 위치 제공자가 없는 기기에서는 수신이 지연될 수 있습니다. 기다리는 동안에도 위치 정확도 설정을 열 수 있으며, 정밀 위치를 허용한 경우 전경에서 GPS와 네트워크를 함께 사용합니다.
- 현재 기본 Drive는 주변 10km의 검사 통과·승인 오디오 중 공개 장소가 등록된 작품을 조회하고, 작품별 장소·반경을 크기가 다른 원으로 표현합니다. 내 주변을 켠 뒤 Play를 누르면 주변 작품을 우선해 Mix로 이어 듣습니다. 보존된 상세 주변 목록 화면에는 1/5/10km 필터와 캐릭터·이야기 정보가 있으며 기본 Drive와 같은 화면은 아닙니다.
- 현재 위치의 오차 원 전체가 크리에이터의 장소 반경 안에 들어올 때만 체류로 판단합니다. 서로 다른 관측 시각 사이에 30초 이상 체류한 캐릭터를 이번 탐색의 만남으로 셉니다. GPS가 부정확하면 방문을 단정하지 않습니다.
- 현재 좌표는 POST 본문으로 HTTPS 전송하며 앱과 API 코드에서는 현재 좌표를 URL·앱 저장소·DB에 남기지 않고 검색에 사용합니다. 실제 인프라 로그의 설정·보유 범위는 운영 연결 시 별도 검증합니다.
- 화면을 떠나거나 앱이 보이지 않으면 위치 수신과 진행 중인 검색을 중단하고 좌표와 검색 결과를 비웁니다. 백그라운드 위치 권한이나 위치 서비스는 없습니다.
- 60초보다 오래되거나 미래/범위 밖/비정상 오차의 좌표는 사용하지 않습니다. 권한 취소 시 요청을 취소하고 기존 위치 기반 결과도 비웁니다.
- 이번 탐색의 만남은 ViewModel 메모리에서만 유지합니다. 회전과 작품 재생 화면 왕복에는 유지되며, 탐색 끄기 또는 프로세스 종료 시 초기화합니다. 서버 방문 기록이나 영구 캐릭터 성장/동기화 기능은 없습니다.
- 작품은 기존 Media3 플레이어로 연결하므로 화면 이동이나 새 위치가 현재 재생을 교체하거나 처음부터 다시 재생하지 않습니다.

## 서버

장소 인덱스는 0005에 있으며 현재 실행에는 0001~0013 전체 마이그레이션을 순서대로 적용해야 합니다. 0013 이후에는 검사 통과 상태도 공개 조건입니다.

```
cd server
npm.cmd run db:migrate
npm.cmd run dev
```

`contents.submission_json`에서 공개 장소의 위도/경도를 계산하는 SQLite 가상 열과 인덱스를 사용합니다. 별도 위치 테이블을 동기화하지 않으므로 승인·수정·차단·공개 중단 상태를 매 요청에 반영합니다. 검수 전/반려/공개 중단 콘텐츠, 장소 미등록 콘텐츠와 로그인 사용자가 차단한 채널은 제외합니다. 권리 확인 진술·원본 파일 이름·해시 등 비공개 제출 정보는 응답하지 않습니다.

날짜변경선과 극지방을 지원하는 경계 상자로 후보를 찾고 구면 거리로 반경 밖을 제외합니다. 자원 사용을 제한하기 위해 경계 상자 안의 최신 500개까지 검사하고, 그 안에서 거리순 최대 20개를 반환합니다. 후보가 넘치거나 20개를 넘으면 `truncated: true`로 일부 결과임을 알립니다. 혼잡 지역 전체의 가장 가까운 20개를 보장하는 전역 지리 인덱스는 아닙니다.

## 확인 방법

1. + 창작에서 공개 장소와 캐릭터/스토리를 입력하고 권리 확인을 마친 오디오를 제출합니다.
2. 파일 검사 통과 후 운영 도구로 장소·권리 정보를 검토하고 해당 revision을 승인합니다. 검사 통과·승인 전에는 주변 검색에 나오지 않아야 합니다. 실제 검사 큐·컨테이너 연결은 후속 작업이며 로컬 시연 seed는 해당 운영 경로를 검증하지 않습니다.
3. 에뮬레이터 Extended controls의 Location 또는 실제 기기로 그 장소 주변 위치를 제공합니다.
4. 대략적인 위치 선택, 권한 거부, 기기 위치 끄기, 앱 백그라운드 전환, 탐색 끄기를 확인합니다.
5. 정확한 위치에서 장소 반경 안에 30초 이상 머무르고 별도 위치 관측이 들어오면 만남이 집계됩니다. 위치 없이 타이머만 지나서는 집계하지 않습니다.
6. 작품을 재생하고 돌아와도 기존 재생 위치가 유지되는지 확인합니다. 주변 승인 작품이 없다면 빈 상태 안내가 정상입니다.

자동 검증: 서버 실제 Workers/D1 테스트에 승인/차단/공개 중단·거리·날짜변경선·극지방·입력 거부·응답 상한을 포함합니다. Rust는 응답의 콘텐츠·좌표·반경·문자열·중복·거리 정렬을 검증하며 Kotlin 단위 테스트는 위치 유효성·오차 기반 체류·30초 관측·중단 시 체류 초기화를 검증합니다.

## 차량 연동 범위

현재 제공되는 위치 소스는 **스마트폰**입니다. 차량 GPS 수신과 차량↔폰 자동 전환은 기업의 SDK/API·인증·데이터 제공 규격을 받을 때까지 보류합니다. Android Auto/Android Automotive OS/외부 차량 GPS의 연결 계약, 갱신 주기·정확도·끊김 판별과 기기 간 인증 경로가 준비되면 이어서 구현합니다.

- Android Auto 연결 감지 `CarConnection`만으로 차량 GPS를 얻을 수는 없습니다.
- Android Auto에서 차량 센서는 유효한 `CarContext`와 Car Hardware API, 위치 권한, 호스트의 실제 센서 제공이 필요합니다. 차량/호스트에 따라 제공되지 않을 수 있습니다.
- Android Automotive OS에서는 CarSensors가 아닌 플랫폼 LocationManager 등 표준 API를 사용하며, 별도 휴대폰으로의 인계에는 기기 간 인증·연결 경로가 필요합니다.
- 현재 Drive와 debug Ink Studio는 OEM 템플릿 UI나 위치 진입에 따른 운전 중 자동 재생을 뜻하지 않습니다. Ink Studio의 가상 지도·샘플 제목·먹물 애니메이션은 재생·위치 API를 호출하지 않는 디자인 시뮬레이션입니다.

공식 근거: [Car Hardware API](https://developer.android.com/training/cars/apps/library/car-hardware-api), [Connection API](https://developer.android.com/training/cars/apps/library/connection-api), [위치 권한](https://developer.android.com/develop/sensors-and-location/location/permissions/runtime).
