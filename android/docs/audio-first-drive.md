# Audio first / Drive — 2026-11-12

> 범위 설명 갱신: 2026-11-13. 아래 2026-11-12 검증 숫자는 당시 실행 이력이며 이번 문서 갱신에서 다시 실행했다는 뜻이 아니다. 최신 인수인계·운영 작업은 [동업자 인수인계](partner-handoff-and-backend-roadmap.md)를 함께 확인한다.

이번 출시의 정체성은 **만들어진 오디오를 올리고 발견하고 듣는 플랫폼**이다.
앱에서 콘텐츠를 생성하지 않는다. 쇼츠·게시글은 후속 업데이트 범위로 옮겼다.

## 현재 구현

- 피드: 전체 / 구독. 검색과 페이지 이동에도 서버에 kind=audio를 지정한다.
- 하단: 피드 / Drive / 창작 / 보관함. 중복 구독 탭은 표시하지 않는다.
- 창작: 오디오와 ZIP만 노출. 실제 비디오 트랙이 있는 파일은 MIME·확장자와 무관하게 거부한다. 기존 권리·파일 해시·검수 절차를 유지한다.
- 보관함: 오디오 Saved / History. 계정·차단·로그인은 상단 프로필.
- 기존 사진 앨범·영상·게시글 데이터와 서버 스키마는 파괴하지 않는다. 이번 앱의 진입점과 재생/제출을 제한하고 이전 화면 복원은 홈으로 보낸다.
- 기존 확장 스키마·코드는 데이터 호환을 위해 유지한다. 기본 앱·웹·API의 제출·수정·승인·공개 목록·상세·미디어·주변 검색은 오디오로 제한한다. `DEV_MODE=1`과 `ENABLE_EXTENDED_FORMATS=1`을 함께 켠 명시적 로컬 회귀 환경에서만 쇼츠·게시글을 허용한다.
- Drive: 어두운 먹빛 바탕, 북쪽 기준 상대 위치, 넓이가 다른 붓 원, 큰 Play / Pause / Next.
- 600dp 이상 가로 화면은 영역과 재생 패널을 좌우 배치한다. 좁은 화면은 세로 배치한다. 방향 고정이나 configChanges 회피를 쓰지 않는다.
- 재생 중 6초 주기의 작은 호흡 효과, 제목 교체 전환, 피드 항목 배치 애니메이션. 화면이 숨겨지거나 일시정지하면 호흡을 중단하고 시스템 애니메이션 비활성화를 존중한다.
- MediaSessionService를 MediaLibraryService로 확장했다. 동일 플레이어가 휴대폰·차량·알림·블루투스의 재생 상태를 공유한다.
- Android Auto 선언과 미디어 브라우저: Drive Mix / 전체 / 구독 / Saved, 오디오 검색 및 검색어 재생 요청.
- 외부 컨트롤러는 Binder에 의해 검증된 UID/Media3 신뢰 상태로 제한한다. 외부가 넘긴 URI로 직접 재생하지 않고 서버에서 승인된 오디오 ID를 다시 조회한다.
- 네트워크·키스토어 준비는 메인 스레드를 막지 않는다. 계정이 바뀌면 대기 응답을 취소하고 큐/위치 추천을 비운다.

## 현대차에 표시되는 화면의 경계

**표준 Android Auto**가 1차 연결 대상이다. 휴대폰 앱 화면을 임의로 현대차 순정 내비 옆에 투사하는 구현이 아니다.
Android Auto는 자신의 내비게이션/미디어 분할 화면과 컨트롤을 호스트가 배치한다.
이번 Compose Drive 그림은 앱에서 사용할 수 있는 실제 화면이자 OEM 협업을 위한 패널 기준이다.
일반 미디어 앱이 순정 내비 옆의 임의 영역을 차지하거나 그 위에 게임형 지도를 그릴 수 있다고 가정하지 않는다.

차종·연식·ccNC/Gen5W/AAOS 여부와 소프트웨어 버전 확인 후 두 경로를 구분한다.

1. Android Auto 지원 차량: 표준 미디어 브라우저로 연결. 내비 안내 시 오디오 포커스 양보, 핸들 버튼, 다음 곡, 화면 재연결을 실차 검증.
2. 현대차 OEM 전용 영역: 별도 SDK·배포 권한·GPS/주행 상태 계약이 있을 때 Drive 렌더러를 연결. 인증·승인 전에는 지원 완료로 표시하지 않는다.

현재 실차 및 Desktop Head Unit 검증은 하지 않았다. 휴대폰 에뮬레이터의 MediaBrowser 연결 테스트는 차량 인증을 대신하지 않는다.
production API 주소·기업 제공 SDK·실차 서명/배포 설정은 기존 보류 범위다.

## 오디오 영역

- 서버의 공개 장소 오디오를 10km 범위로 조회한다.
- 1.5km 이내의 장소들을 안정적인 ID 순서로 묶는다.
- 반경 = max(1.5km, 장소 간 거리 + 기존 반경, 1.5km + 추가 콘텐츠 수 × 350m), 상한 5km.
- 따라서 포인트별로 동일한 작은 반경을 복제하지 않는다. 창작자가 입력한 정밀 장소/방문 반경은 수정하지 않는다.
- 화면의 원 크기와 실제 추천 영역은 같은 AudioRegion을 사용한다.
- 위치 오차를 포함해 영역 안에 있다고 판단할 때만 그 영역을 우선 추천한다. 서로 겹치는 영역은 후보를 합쳐 중복 제거한다.
- 장소/좌표가 없는 오디오는 일반 Mix에 남는다. 지도에 가짜 도로나 가짜 콘텐츠 지점을 만들어 넣지 않는다.
- 상대 좌표는 날짜 변경선 경도를 보정한다. 도로 지도·경로 안내·주행 방향 표시 기능은 아니다.
- 지역 검색 응답의 제한으로 모든 오디오가 포함된다는 보장은 없다. 다음 서버 버전에서 audio 전용 공간 쿼리/페이지 이동이 필요하다.

## 추천과 재생

현재 모델은 서버의 검색 가능한 키워드 + 주변 영역 우선 + 무작위 순서 + 세션 내 중복 제외다.
Tune에서 Mix / Calm(자연) / Story(이야기) 또는 직접 키워드를 저장한다. 주제를 지정하면 지역 후보도 검색 결과에 해당하는 것만 포함한다.
기존 서버의 최대 50개 후보를 사용하며 이를 학습 모델이나 인기 순위라고 표시하지 않는다.

- 사용자가 Play / Drive Mix를 명시적으로 선택해야 시작한다. 앱 실행이나 영역 진입만으로 소리가 나지 않는다.
- 후보를 최대 12개씩 승인·차단·삭제 상태와 HTTPS 재생 주소를 재검증한 뒤 큐에 넣는다.
- 남은 큐가 짧아질 때 다음 묶음을 보충한다. 위치 변경으로 현재 재생을 중간에 교체하지 않는다.
- 이미 준비된 큐는 유지하고 새 추천 묶음에 새 위치/취향을 반영한다. 즉시 바꾸려면 New mix.
- 최근 큐 ID는 최대 200개, 지난 MediaItem은 12개까지 유지한다. 후보 소진 시 억지로 반복하지 않고 종료한다.
- 통신 오류로 다음 큐를 만들지 못하면 준비된 오디오를 유지한다. 원본 스트림 캐시/오프라인 다운로드는 별도 기능이다.
- 좌표와 이동 기록은 저장하지 않는다. 전경 위치 수신만 사용한다. 화면을 떠나면 위치 수신/지역 추천을 비운다. 지역 추천 ID도 60초가 지나면 만료된다.
- 따라서 휴대폰 화면이 꺼진 Android Auto 주행 중에는 일반 Mix 재생은 가능하지만 **지속적인 차량 위치 기반 추천은 아직 제공하지 않는다.**

## 후속 차량 위치/인기 추천 계약

기업 SDK 제공 후 다음을 구현/검증한다.

- LocationProvider 입력: 좌표, 정확도, 관측 monotonic time, source(phone/vehicle), connection generation.
- 차량 연결 중 신선하고 정확한 차량 GPS 우선. 끊김/신호 만료 시 허가된 폰 위치로 전환. 두 소스가 모두 유효하지 않으면 위치 우선순위만 해제하고 오디오는 계속 재생.
- 속도에 따라 수신 빈도/앞쪽 영역을 조절하되 GPS 흔들림으로 큐가 바뀌지 않도록 진입 20초, 이탈 여유 거리 및 소스 전환 히스테리시스를 실차에서 보정.
- 백그라운드 위치가 필요하면 사용자 시작 주행 세션과 foreground location service를 먼저 설계하고 별도 권한/스토어 검토. 현재 앱에는 무조건 켜지는 백그라운드 추적을 넣지 않는다.
- 인기 지표: 유효 청취 시간·완주·저장·스킵, 시간 감쇠, 반복/봇 요청 제한. 지역 크리에이터와 신작 탐색 슬롯을 보장한다.
- 서버 추천 결과: content_id, region_id, reason(topic/nearby/popular/explore), expires_at, 다음 커서. 단말은 스트림 URL을 영구 저장하지 않는다.
- 학습/인기 지표는 개인정보 수집 범위와 보존 정책을 정한 후에 도입한다. 가짜 조회수나 무작위 인기 점수는 사용하지 않는다.
